# 🌎 Dynamic Weather Globe Dashboard

A real-time **3D Weather Dashboard** that visualizes global weather data using a **rotating Earth model** and interactive map.  
Built with **HTML**, **CSS**, and **JavaScript** — powered by **Three.js**, **Leaflet**, and the **OpenWeatherMap API**.

## 🚀 Features

- 🌐 **3D Rotating Earth** using Three.js  
- 🗺️ **Interactive Map View** (Leaflet)  
- 🔍 **City Search + Autocomplete**  
- 📍 **Use My Location** for instant local weather  
- 🌤️ **Current Weather & 3-Day Forecast**  
- 🌓 **Light / Dark Mode Toggle**  
- ⚡ **Responsive & Animated UI**

## 🧠 Tech Stack

- **HTML5** — Structure and layout  
- **CSS3** — Styling, glassmorphism, and responsiveness  
- **JavaScript (ES6)** — Logic and API handling  
- **Three.js** — 3D globe rendering  
- **Leaflet.js** — Map integration  
- **OpenWeatherMap API** — Real-time weather data
